Thursday, 19 November 2026, in one image: a newspaper front page. The masthead names the date; the illustration shows the day's top story — the first-ever Trump-Xi-Putin trilateral summit in Shenzhen — and five reported stories are set beneath it: the Gulf war spreading to US bases in Kuwait and Bahrain, Anthropic's record $81.3bn IPO, a Van Gogh selling for $190.4m, Voyager 1 reaching one light-day from Earth, and GTA VI's global rollout.

The image is drawn in this session by `draw_frontpage.py` (Pillow) and shipped as `assets/entry.png`; `main.py` copies it to the output directory.

## Run it

```sh
python3 main.py
```

It copies `assets/entry.png` to `/output/entry.png` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside the grader).
